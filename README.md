## About
Understand bagging vs. boosting ensemble models, explore boosting’s impact on bias-variance, compare AdaBoost and gradient boosting, and learn to build and evaluate models like XGBoost.


## Learning Objectives

*You will be able to:*

- Understand the differences between bagging and boosting.
- Learn the pros and cons to using boosting models.
- Learn the effect of boosting on the bias-variance trade-off.
- Learn the math and procedure for AdaBoost, a classic boosting model.
- Understand the differences between AdaBoost and gradient-boosting models.
- Build an XGBoost model.
